# Visualizations

This folder organizes the **Employee Attrition & Workforce Analytics using Python** project.

- Generate histograms, box plots, bar charts, count plots, scatter plots, and a correlation heatmap.
- The provided dataset has no suitable event-date field for a valid time-series chart; this limitation is documented in the notebook.
- Charts are generated into the outputs/figures folder when the notebook is run.

**Main implementation:** [`../Employee_Attrition_Workforce_Analytics.ipynb`](../Employee_Attrition_Workforce_Analytics.ipynb)
