# Attrition Analysis

This folder organizes the **Employee Attrition & Workforce Analytics using Python** project.

- Calculate the overall attrition rate.
- Compare attrition by department, job role, overtime, income, satisfaction, distance, age, and work-life balance.
- Interpret group sizes alongside rates.
